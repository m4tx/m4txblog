I'm an open-source contributor, enthusiast of Rust and GNU/Linux, CTF participant, and competitive Riichi Mahjong player. I'm one of the founders and currently the president of [Krakow Chombo Club](https://chombo.club).

I'm using Arch Linux (btw) and I'm [maintaining a number of packages in the Arch User Repository (AUR)](https://aur.archlinux.org/packages?O=0&SeB=M&K=m4tx&outdated=&SB=p&SO=d&PP=50&submit=Go).

Currently working at Google as a Software Engineer in the Pixel Core Platform Team.

## Projects

* [Cot](https://cot.rs), the Rust web framework for lazy developers.
* [Tundra](https://github.com/m4tx/tundra), a MyAnimeList scrobbler for Linux.
* [dtoolkit](https://github.com/google/dtoolkit), a Rust library for parsing and manipulating Flattened Device Tree (FDT) blobs.
